# CryVPN

Настольное приложение сервиса CryVPN для Windows. Ставится на компьютер,
получает подписку и поднимает VPN-туннель одной кнопкой.

Установщик лежит в разделе [Releases](../../releases). Рядом с ним —
файл `.sha256` с контрольной суммой.

## Что умеет

- вход по кнопке «Добавить подписку» со страницы подписки или почтой и
  кодом из письма;
- список серверов из подписки, замер задержки, остаток трафика;
- туннель на весь компьютер (TUN) на ядре Xray;
- автозапуск вместе с Windows.

## Как это устроено

Приложение собрано на [Tauri](https://tauri.app): окно — React, нативная
часть — Rust. Своего VPN-протокола здесь нет: туннель поднимает
[Xray-core](https://github.com/XTLS/Xray-core) через драйвер
[Wintun](https://www.wintun.net). Оба кладутся в установщик готовыми
файлами; при сборке скачанное сверяется с контрольными суммами,
записанными в `scripts/resources.ps1`.

Правила маршрутизации приложение не выдумывает — они приходят вместе с
подпиской. Приложение добавляет только туннельный вход.

Для туннеля нужны права администратора: без них Windows не даёт создать
сетевой адаптер и менять маршруты. Права запрашиваются один раз при
запуске.

## Что приложение хранит и чего не хранит

В самом приложении нет ни ключей, ни паролей, ни служебных доступов.
Оно обращается к тому же общедоступному API, что и сайт сервиса, и
может ровно то, что может сам пользователь в своём кабинете.

На компьютере остаётся только:

- сессия входа и адрес подписки — зашифрованы средствами Windows (DPAPI)
  под учётную запись; если зашифровать не удалось, не сохраняются вовсе;
- настройки приложения.

Не сохраняются: конфигурация туннеля с ключами подписки (стирается
сразу после запуска ядра) и журнал посещённых адресов (его запись в ядре
выключена).

## Ссылки `cryvpn://`

Кнопка «Добавить подписку» открывает ссылку вида
`cryvpn://add/<адрес подписки>`. Разбор строгий и покрыт проверками
(`src-tauri/src/link.rs`): только `https`, только домены сервиса, только
короткий код в пути. Приложение запускает ядро с правами администратора
на конфигурации с этого адреса, поэтому посторонний адрес по подсунутой
ссылке оно не примет.

## Чтобы после приложения сеть оставалась целой

- системный прокси, настройки DNS других адаптеров, брандмауэр и файл
  `hosts` приложение не трогает;
- туннельный адаптер исчезает вместе с ядром, маршруты уходят с ним;
- если приложение сняли принудительно с поднятым туннелем, при следующем
  запуске оно само убирает оставшееся;
- обрыв туннеля виден в окне: приложение не пишет «Подключено», когда
  трафик идёт напрямую.

## Сборка

Нужны Windows 10/11, Node.js, Rust (msvc) и инструменты сборки Microsoft.

```
powershell -ExecutionPolicy Bypass -File scripts\resources.ps1
npm ci
npm run tauri build
```

Установщик появится в `src-tauri/target/release/bundle/nsis/`.

Выпуски собираются не вручную, а автоматически из этого репозитория —
см. `.github/workflows/release.yml`. Проверить скачанный файл:

```
certutil -hashfile CryVPN-Setup.exe SHA256
```

и сравнить с содержимым `CryVPN-Setup.exe.sha256` из того же выпуска.

В коде есть и ветка для macOS (`scripts/resources-macos.sh`,
`scripts/build-macos.sh`). Она рабочая, но выпуски для macOS не
публикуются: без подписи Apple приложение не открывается у пользователей.

## Что приложение меняет в системе

Установщик и приложение делают только перечисленное, и всё это
убирается при удалении:

- ставят программу в папку пользователя и добавляют её в «Пуск»;
- регистрируют ссылки `cryvpn://`, чтобы работала кнопка «Добавить
  подписку»;
- на время подключения создают сетевой адаптер `CryVPN` и маршруты
  через него; после отключения адаптер и маршруты исчезают;
- если включён автозапуск — создают задание в Планировщике Windows.

Приложение удаляется обычным способом: «Параметры → Приложения».

## Privacy policy

CryVPN — клиент платного сервиса, и без обращения к его серверам он
работать не может. Передаётся только то, что нужно для входа и
подключения, и только на серверы самого сервиса:

- **при входе почтой** — адрес почты и код из письма, на
  `api.cryvps.com`;
- **при получении подписки** — идентификатор устройства, название и
  версия системы, имя компьютера, на сервер подписки. Сервис считает по
  ним число устройств на подписке;
- **при подключении** — ваш сетевой трафик идёт через выбранный вами
  VPN-сервер сервиса. Это и есть назначение программы;
- **при проверке обновлений** (Windows) — раз в час приложение читает
  описание последнего выпуска с GitHub, из этого репозитория, а по
  кнопке «Обновить» скачивает оттуда установщик и сверяет его SHA-256.
  Никаких данных о вас при этом не отправляется; GitHub, как любой
  сайт, видит ваш IP-адрес.

Приложение не содержит аналитики, рекламы и счётчиков, не собирает
историю посещений и ничего не передаёт третьим лицам. Сторонние
компоненты (Xray-core, Wintun) собственных обращений в сеть, кроме
самого туннеля, не делают.
